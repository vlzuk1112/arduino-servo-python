# 🤖 Arduino Servo Controller with Python GUI

[![Python Version](https://shields.io)](https://python.org)
[![Arduino](https://shields.io)](https://arduino.cc)
[![License: MIT](https://shields.io)](https://opensource.org)

Красивый и удобный графический интерфейс (GUI) на **Python 3.12** для плавного управления сервоприводом, подключенным к плате **Arduino**. Связь между компьютером и микроконтроллером реализована через протокол **Firmata**.

---

## ✨ Ключевые особенности

*   🔍 **Умный автопоиск портов:** Скрипт сам сканирует систему и подключается к Arduino (поддерживает оригинальные платы и китайские клоны на чипе CH340). Вам не нужно вручную прописывать `COM3` или `COM4`.
*   🎛️ **Плавный слайдер:** Управление углом поворота сервопривода (от 0° до 180°) в реальном времени с помощью мыши.
*   ⚡ **Быстрые пресеты:** Кнопки мгновенного перевода вала в популярные положения: `0°`, `90°` и `180°`.
*   🛡️ **Безопасное отключение:** При закрытии окна программа корректно освобождает COM-порт, предотвращая зависание платы в системе.

---

## 🛠️ Схема подключения (Hardware)

1.  **Сервопривод (например, SG90):**
    *   🟤 / ⚫ **GND** (Коричневый/Черный) ➔ **GND** на Arduino
    *   🔴 **VCC** (Красный) ➔ **5V** на Arduino
    *   🟡 / 🟠 **Signal** (Желтый/Оранжевый) ➔ **Digital Pin 9** (D9) на Arduino
2.  Подключите плату Arduino к компьютеру через USB-кабель.

## 🚀 Быстрый старт

### 1. Подготовка Arduino
*   Откройте **Arduino IDE**.
*   Перейдите в `Файл` ➔ `Примеры` ➔ `Firmata` ➔ **`StandardFirmata`**.
*   Загрузите (Upload) этот скетч в вашу плату. После этого Arduino IDE можно закрыть.

### 2. Установка зависимостей на ПК
Убедитесь, что у вас установлен **Python 3.12**. Откройте терминал (PowerShell или командную строку) и выполните:

```bash
pip install pyfirmata2 pyserial
```

### 3. Запуск приложения
Скачайте скрипт `servo_windows.py` и запустите его:

```bash
python servo_windows.py
```
